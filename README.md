# BrainAgeEngine

Predict brain age from neuroimaging features and quantify brain age gap as a biomarker of cognitive decline.

## Features

- Brain age prediction from structural MRI features
- Brain age gap (BAG) computation and interpretation
- Aging trajectory modeling across 20-90 year range
- Cognitive decline correlation with BAG
- Neurodegeneration clock calibration

## Results

500 subjects (20-90y); Prediction r=0.879; MAE=8.2y; BAG-MMSE r=-0.807

## Usage

```bash
pip install numpy scipy matplotlib
python brain_age_engine.py
```
